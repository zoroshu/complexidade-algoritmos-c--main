# Análise de Complexidade de Algoritmos de Ordenação e Busca  
# Complexity Analysis of Sorting and Searching Algorithms

---

## 🇧🇷 Português

Este repositório apresenta o relatório **“Análise de Complexidade de Algoritmos de Ordenação e Busca”**, desenvolvido no contexto da disciplina **SIN213 – Projeto de Algoritmo**, do curso de **Sistemas de Informação** da **Universidade Federal de Viçosa (UFV) – Campus Rio Paranaíba**.

O trabalho tem como objetivo analisar, de forma **teórica e experimental**, o desempenho de algoritmos clássicos de ordenação, considerando diferentes cenários de entrada e utilizando conceitos formais da análise de complexidade computacional.

---

### 📄 Sobre o Relatório

O relatório aborda conceitos fundamentais da Ciência da Computação, com foco em:

- Complexidade temporal e espacial  
- Casos **melhor**, **médio** e **pior**  
- Notações assintóticas **Big-O (O)**, **Theta (Θ)** e **Omega (Ω)**  
- Análises matemáticas com recorrências, tabelas de custo e testes de mesa  
- Avaliação empírica baseada em medições reais de tempo de execução  

Além da fundamentação teórica, o estudo apresenta **tabelas e gráficos comparativos** que demonstram o comportamento dos algoritmos conforme o crescimento do tamanho da entrada.

---

### 🧠 Algoritmos Analisados

- Insertion Sort  
- Bubble Sort  
- Selection Sort  
- Shell Sort  
- Merge Sort  
- Quick Sort  
- Heap Sort  

Cada algoritmo é analisado quanto a:
- Funcionamento e características  
- Estabilidade  
- Uso de memória  
- Complexidade assintótica  
- Desempenho prático com entradas crescentes, decrescentes e aleatórias  

---

### 📊 Análises Experimentais

Foram realizados testes de desempenho com diferentes tamanhos de entrada:

- 10  
- 100  
- 1.000  
- 10.000  
- 100.000  
- 1.000.000 elementos  

Os resultados são apresentados por meio de **tabelas**, **gráficos** e **análises interpretativas**, permitindo comparar algoritmos quadráticos e algoritmos de ordem *O(n log n)*.

## 🇺🇸 English

This repository presents the report **“Complexity Analysis of Sorting and Searching Algorithms”**, developed as part of the course **SIN213 – Algorithm Project**, within the **Information Systems** undergraduate program at the **Federal University of Viçosa (UFV) – Rio Paranaíba Campus**.

The objective of this work is to perform a **theoretical and experimental analysis** of classic sorting algorithms, evaluating their performance under different input scenarios using formal tools from computational complexity analysis.

---

### 📄 About the Report

The report covers fundamental topics in Computer Science, focusing on:

- Time and space complexity  
- **Best**, **average**, and **worst** cases  
- Asymptotic notations **Big-O (O)**, **Theta (Θ)**, and **Omega (Ω)**  
- Mathematical analysis using recurrences, cost tables, and step-by-step execution  
- Empirical evaluation based on real execution-time measurements  

In addition to the theoretical foundation, the study includes **tables and comparative charts** that illustrate algorithm behavior as input size increases.

---

### 🧠 Analyzed Algorithms

- Insertion Sort  
- Bubble Sort  
- Selection Sort  
- Shell Sort  
- Merge Sort  
- Quick Sort  
- Heap Sort  

Each algorithm is evaluated in terms of:
- Operational behavior  
- Stability  
- Memory usage  
- Asymptotic complexity  
- Practical performance with sorted, reverse-sorted, and random inputs  

---

### 📊 Experimental Analysis

Performance tests were conducted using different input sizes:

- 10  
- 100  
- 1,000  
- 10,000  
- 100,000  
- 1,000,000 elements  

The results are presented through **tables**, **charts**, and **interpretive analysis**, enabling clear comparison between quadratic algorithms and *O(n log n)* algorithms.
